# Geoportal Municipal de Porteiras

WebGIS para consulta da ortofoto municipal de Porteiras (CE), camadas de referência e medições compartilhadas.

## Recursos

- Ortofoto municipal com resolução original de 2,5 cm/pixel.
- Google Satellite e Google Roads como camadas de referência.
- Coordenadas em graus decimais ou SIRGAS 2000 / UTM zona 24S.
- Medição de linha reta, caminhos segmentados e áreas.
- Medições salvas em banco compartilhado.
- Interface responsiva para computadores, tablets e celulares.
- Transparência aplicada aos pixels nodata e brancos da ortofoto.

O arquivo ECW original não é armazenado neste repositório. A versão publicada usa um arquivo PMTiles hospedado em armazenamento de objetos com suporte a requisições parciais.
